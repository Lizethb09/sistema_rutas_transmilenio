# Actividad 4 - Metodos de aprendizaje no supervisado

## Proyecto
Sistema inteligente para explorar agrupaciones de trayectos hipoteticos de TransMilenio mediante K-Means.

## Autora
Lizeth Valentina Benitez - Ingenieria de Software - IBERO - 2026

## Objetivo
Aplicar K-Means para agrupar trayectos hipoteticos usando el numero de estaciones, el costo interno sintetico y los transbordos.

## Archivos del proyecto
- datos/dataset_trayectos_no_supervisado.csv: conjunto de datos sinteticos.
- modelo_no_supervisado.py: codigo del modelo.
- documentacion/descripcion_datos.md: descripcion de los datos.
- documentacion/documento_pruebas.md: documentacion de pruebas.
- pruebas/resultados_agrupamiento.csv: resultados por trayecto.
- pruebas/resumen_grupos.csv: resumen estadistico.
- pruebas/grafica_agrupamiento.png: grafica de resultados.

## Resultados
- Registros procesados: 36.
- Grupo 1: 13 trayectos.
- Grupo 2: 11 trayectos.
- Grupo 3: 12 trayectos.
- Puntuacion de silueta: 0.5301.

## Limitaciones
El conjunto contiene datos sinteticos creados con fines academicos. No son datos operativos oficiales de TransMilenio. Los grupos son identificadores del algoritmo y no categorias oficiales.
